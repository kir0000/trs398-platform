# Перед тем как сделать репозиторий публичным

Решение владельца: таблицы IAEA (`core/data/photon_tables.json`, `core/data/electron_tables.json`) остаются в репозитории.
Пока репозиторий приватный, это не вопрос. Перед открытием:

1. Проверить условия использования TRS-398 Rev.1 (https://doi.org/10.61092/iaea.ve7q-y94k) на предмет
   распространения таблиц kQ (16, 20, 21) и ks (10). Если распространение не разрешено, удалить два JSON-файла
   (в том числе из истории git) и оставить скрипты `importers/`: таблицы строятся из собственных листов пользователя.
2. Убедиться, что в истории git нет реальных данных: `.env`, `backups/`, `tests/data/*.json`, `docs/sample_*.pdf`
   игнорируются; проверить `git log --stat` на посторонние файлы.
3. Заменить в README адрес репозитория и контакты, оставить медицинскую оговорку из `NOTICE.md`.
4. Прогнать `pytest`, `tools/recompute_check.py` и CI.
5. Только после этого: Settings → General → Change visibility.

# Выпуск версий и передача на компьютеры без интернета

На компьютерах больницы часто нет ни GitHub, ни интернета. Поэтому каждая версия выпускается в виде пакета, который переносится
флешкой или сетевой папкой; GitHub нужен только вам, чтобы получить готовый пакет.

## Как выпустить версию

1. Убедитесь, что тесты проходят (`.venv\Scripts\python -m pytest -q tests`) и всё закоммичено.
2. Поставьте тег: `git tag v1.0.0` и `git push origin v1.0.0`. GitHub Actions соберёт образ (он попадёт в `ghcr.io/kir0000/trs398-app:1.0.0`)
   и приложит к странице релиза (Releases) два файла:
   - `TRS398-1.0.0-offline.zip`: всё вместе с образами Docker внутри (около 0,5–0,7 ГБ), для компьютеров без интернета;
   - `TRS398-1.0.0-installer.zip`: то же без образов (малый размер), образы скачиваются при запуске (нужен интернет и открытый пакет в ghcr.io).
3. То же можно сделать у себя без GitHub: `python tools/make_bundle.py 1.0.0` (нужен Docker); пакеты появятся в папке `dist/`.
4. Версия видна в программе (внизу страницы, `/healthz`) и в имени образа; номер берётся из тега или из файла `VERSION`.

## Установка на компьютере без интернета

1. Установите Docker Desktop из установщика, который выдаст ИТ-отдел (он не входит в пакет: у него своя лицензия), и WSL 2
   (на закрытых сетях ИТ-отдел ставит и его заранее). Подробно: `INSTALL.md`.
2. Скопируйте `TRS398-<версия>-offline.zip` на компьютер, распакуйте в папку без русских букв, например `C:\trs398`.
3. Проверьте целостность (по желанию): `certutil -hashfile TRS398-<версия>-offline.zip SHA256`, сравните с суммой на странице релиза.
4. Запустите `start.bat`: образы загрузятся из пакета (несколько минут, один раз), затем откроется браузер. Дальше как в `INSTALL.md`.

## Обновление до новой версии

1. Распакуйте новый `TRS398-<версия>-offline.zip` поверх старой папки: файлы `.env`, папки `backups` и `certs` в пакете нет, они сохранятся.
2. Запустите `update.bat`: он сделает резервную копию, загрузит образы новой версии, перезапустит программу и применит изменения схемы базы.
3. Если что-то пошло не так, восстановите резервную копию (`restore.bat`) и запустите прежнюю версию.

## Что публикуется (открытый код)

Образ и репозиторий содержат код программы, документацию и справочные таблицы. В них нет данных пациентов, паролей и ваших измерений:
`.env`, `backups/` и базы остаются на вашем компьютере. Образ в ghcr.io по умолчанию закрыт; чтобы любой мог скачать его без входа,
после первой публикации откройте: профиль → Packages → trs398-app → Package settings → Change visibility → Public.
Перед открытием репозитория пройдите чек-лист выше (в начале этого файла).
