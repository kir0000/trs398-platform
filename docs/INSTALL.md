# Установка и запуск (Windows)

Нужен Windows 10 или 11. Docker, Python и серверы баз данных **не нужны**. Для PDF используется Microsoft Edge (он есть в Windows 10/11) или Chrome.

## Установка

**Права администратора не нужны ни для установки, ни для работы**: установщик пишет только в профиль пользователя, портативная версия запускается из любой папки, куда можно писать (рабочий стол, `Документы`, флешка). Исключение: разрешение брандмауэра для доступа с других ноутбуков ([NETWORK.md](NETWORK.md)). Если запуск блокирует политика организации (AppLocker, антивирус), нужна помощь ИТ-администратора: исключение для папки программы.

1. Со страницы **Releases** репозитория скачайте `TRS398-setup-….exe` и запустите. Права администратора не нужны, программа ставится в профиль пользователя
   (`%LOCALAPPDATA%\Programs\TRS398`); можно выбрать другую папку и отметить «запускать вместе с Windows».
2. Если Windows пишет «Система Windows защитила ваш компьютер» (SmartScreen): нажмите **Подробнее → Выполнить в любом случае**. Так бывает с любой программой без платной подписи.
3. Запустите **TRS-398** из меню «Пуск». Возле часов появится значок, откроется `http://localhost:8000`.
4. Первый вход: придумайте логин и пароль администратора (не короче 10 символов). Эта страница доступна, только пока в базе нет пользователей.

**Без установки:** скачайте `TRS398-portable-….zip`, распакуйте в любую папку (например, на флешку или `C:\trs398`), запустите `TRS398.exe`. Данные будут в папке `data` рядом.

## Повседневная работа

- Значок возле часов: щелчок открывает программу, правая кнопка даёт меню (копия, папка с данными, восстановление, автозапуск, доступ с других компьютеров, выход).
  Если значка не видно, он спрятан под стрелкой «^» около часов.
- Закрыли браузер: программа продолжает работать, откройте её снова значком или ярлыком. Остановить: «Выход».
- Копии делаются сами каждый день, пока программа запущена. Раз в неделю-две копируйте папку `backups` на другой носитель.

## Обновление

Скачайте новый установщик и запустите его поверх: программа заменится, **данные не трогаются**. Для портативной версии: распакуйте новый zip поверх старой папки, папку `data` не удаляйте.
Перед обновлением сделайте копию (меню значка).

## Удаление

«Параметры → Приложения → TRS-398 → Удалить». Данные (`%LOCALAPPDATA%\TRS398\data`) удаляются только вами вручную.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| Значок есть, страница не открывается | Нажмите значок. Если порт 8000 занят другой программой, измените `port` в файле `settings.json` в папке данных (например, 8100) и перезапустите. |
| «PDF недоступен» | Нужен Edge или Chrome. Запасной путь: кнопка «Печать» → «Сохранить как PDF». |
| Антивирус удалил или заблокировал программу | Добавьте папку программы в исключения. Сборка не подписана. |
| Забыли пароль администратора | Другой администратор сбрасывает пароль в «Пользователях». Если администратор один: восстановите копию, где пароль известен, или начните с пустой базы (см. README). |
| Нужно вернуть данные | Меню значка → «Восстановить из копии…». |

## Запуск из исходников (для разработчиков)

`pip install -r requirements.txt`, затем `python run.py` (без значка) или `python tray.py`. Данные: папка `data` проекта или переменная `TRS_DATA`.
