# Установка Docker Desktop и запуск программы (Windows)

Вся программа (веб-сайт, база данных, резервные копии) работает в Docker. Ставить нужно только Docker Desktop, больше ничего
(ни Python, ни PostgreSQL). Время: около 30 минут, из них почти всё занимает скачивание.

## 0. Что нужно заранее

| | |
|---|---|
| Система | Windows 10 (22H2, 64-бит) или Windows 11, любая редакция (Home тоже подходит) |
| Процессор | 64-бит с включённой виртуализацией (почти все современные) |
| Память | от 8 ГБ, лучше 16 ГБ; программе хватает 2–3 ГБ |
| Диск | свободно 10 ГБ |
| Права | один раз нужен администратор Windows (для установки) |
| Интернет | нужен при первой установке и первой сборке (скачивается около 1 ГБ), потом программа работает без интернета |

**Лицензия Docker Desktop.** Для личного, учебного и некоммерческого использования и для небольших компаний (меньше 250 сотрудников
и меньше 10 млн долларов годового дохода) он бесплатен. Для крупных организаций нужна платная подписка Docker. Для больницы
или центра уточните это у ИТ-отдела до установки. Альтернатива без этого ограничения: сервер на Linux (см. в конце).

## 1. Проверьте виртуализацию

1. Нажмите `Ctrl+Shift+Esc` (Диспетчер задач) → вкладка **Производительность** → **ЦП**.
2. Внизу справа должно быть **Виртуализация: Включено**.
3. Если написано «Отключено», её включают в BIOS/UEFI (при загрузке компьютера клавиша `Del`, `F2` или `F10`): пункт
   **Intel Virtualization Technology (VT-x)** или у AMD **SVM Mode**, значение **Enabled**. Сохранить и перезагрузиться.
   На рабочих компьютерах больницы это обычно делает ИТ-отдел.

## 2. Скачайте и установите

1. Откройте https://www.docker.com/products/docker-desktop/ и нажмите **Download for Windows**
   (обычный компьютер: **AMD64**; ноутбуки на Windows с процессором Snapdragon: ARM64).
2. Запустите `Docker Desktop Installer.exe` (на запрос контроля учётных записей ответьте «Да»).
3. В окне установки **оставьте галочку «Use WSL 2 instead of Hyper-V»** (рекомендуется; для Windows Home это единственный вариант) и
   «Add shortcut to desktop». Нажмите **OK** и дождитесь конца установки (5–10 минут).
4. Нажмите **Close and restart** (или **Close**, а потом перезагрузите компьютер сами). **Перезагрузка обязательна.**
5. Если установщик пишет, что нужно установить WSL: откройте **PowerShell от имени администратора** (правый щелчок по «Пуск» →
   «Терминал (Администратор)») и выполните `wsl --install`, перезагрузитесь, затем запустите Docker Desktop снова.

## 3. Первый запуск

1. После перезагрузки запустится Docker Desktop (или найдите его в меню «Пуск»). Примите условия лицензии (**Accept**).
2. Предложение зарегистрироваться или войти можно пропустить: **Skip** / «Continue without signing in». Аккаунт Docker не нужен.
3. Опрос «Tell us about yourself» тоже можно пропустить.
4. Подождите, пока внизу слева значок станет **зелёным** и появится надпись **Engine running** (первый раз до 1–2 минут).
5. Проверка: откройте PowerShell и выполните

   ```
   docker --version
   docker run --rm hello-world
   ```

   Вторая команда скачает маленький образ и напишет «Hello from Docker!». Значит всё готово.

**Если вы работаете не под администратором** (обычная учётная запись больницы): добавьте её в группу `docker-users`.
Это делает администратор один раз, в PowerShell от администратора: `net localgroup docker-users "ИМЯ-КОМПЬЮТЕРА\имя-пользователя" /add`
(для доменной учётной записи: `"ДОМЕН\имя"`), затем пользователь выходит из Windows и входит снова.

## 4. Настройки Docker Desktop (шестерёнка вверху справа)

Для компьютера, на котором программа должна работать постоянно (сервер):

| Раздел | Настройка | Значение |
|---|---|---|
| General | **Start Docker Desktop when you sign in to your computer** | включить (иначе после перезагрузки программа не поднимется сама) |
| General | **Use the WSL 2 based engine** | включено |
| General | **Open Docker Dashboard when Docker Desktop starts** | выключить (не мешает окно) |
| General | **Send usage statistics** | по желанию выключить |
| Software updates | автоматическая проверка обновлений | по желанию; обновлять в нерабочее время |
| Resources → WSL integration | **Enable integration with my default WSL distro** | можно оставить как есть |

Дальше менять ничего не нужно. Контейнеры программы помечены `restart: unless-stopped`: после перезагрузки компьютера и запуска Docker
Desktop они поднимаются сами.

**Память (необязательно).** По умолчанию WSL может занять до половины оперативной памяти. Чтобы ограничить: создайте файл
`C:\Users\ВАШЕ_ИМЯ\.wslconfig` с текстом

```
[wsl2]
memory=4GB
processors=2
```

затем в PowerShell `wsl --shutdown` и перезапустите Docker Desktop.

**Если в сети больницы есть прокси.** Settings → Resources → Proxies: включите **Manual proxy configuration** и введите адрес,
который даст ИТ-отдел. Если сборка падает с ошибкой сертификата при скачивании, ИТ-отделу нужно добавить Docker Hub
(`registry-1.docker.io`, `auth.docker.io`, `production.cloudflare.docker.com`) в разрешённые или установить корпоративный сертификат.

## 5. Запустите программу

1. Скачайте проект: на странице репозитория **Code → Download ZIP**, распакуйте, например, в `C:\trs398` (путь без русских букв и
   пробелов надёжнее). Или `git clone`.
2. Убедитесь, что Docker Desktop запущен (**Engine running**).
3. Дважды щёлкните **`start.bat`**. Сначала он проверяет компьютер (Windows, виртуализация, WSL 2, Docker Desktop, место на диске, порт)
   и объясняет на выбранном языке, что исправить; WSL предложит установить сам, а Docker Desktop при необходимости запустит. При первом запуске спросит язык (русский или English; позже его меняет `language.bat`). Затем первый раз он скачивает образы и собирает программу (5–15 минут), затем сам откроет браузер на
   `http://localhost:8000`. Если Windows пишет «Защитник Windows SmartScreen защитил компьютер», нажмите «Подробнее» → «Выполнить в любом случае».
4. В браузере появится страница **«Первый запуск»**: придумайте логин, фамилию с инициалами и пароль администратора (не короче 10 символов).
5. Дальше: «Пользователи» (физики и проверяющие), «Оборудование», «Измерения». Подробно: [USER_GUIDE.md](USER_GUIDE.md).

Брандмауэр Windows при первом запуске может спросить про доступ для Docker/`com.docker.backend`: разрешите для **частных** сетей.

## 6. Компьютер-сервер для всей группы

1. Выполните шаги 1–5 на одном постоянно включённом компьютере.
2. Включите в Windows **отключение сна** (Параметры → Система → Питание → «Режим сна»: Никогда), а в Docker Desktop автозапуск (раздел 4).
   В Windows должен быть выполнен вход пользователя (экран можно заблокировать, но нельзя выходить из учётной записи).
3. Запустите **`lan-on.bat`**: он откроет порт 8000 для других компьютеров сети и покажет адреса. Подробно: [NETWORK.md](NETWORK.md).
4. В роутере закрепите за сервером постоянный IP-адрес (или пользуйтесь именем компьютера).
5. Папку `backups` периодически копируйте на другой диск или сетевую папку.

## 7. Если что-то не работает

Проверку можно запустить отдельно, без запуска программы: `powershell -ExecutionPolicy Bypass -File tools\preflight.ps1 -Lang ru` (или `-Lang en`).

| Что видно | Что делать |
|---|---|
| «Docker Desktop is not running» в `start.bat` | запустите Docker Desktop, дождитесь **Engine running**, повторите |
| Docker Desktop зависает на «Starting…» | перезагрузите компьютер; проверьте виртуализацию (раздел 1); в PowerShell от администратора `wsl --update` и `wsl --shutdown` |
| «WSL 2 installation is incomplete» | в PowerShell от администратора `wsl --install`, перезагрузка |
| Страница http://localhost:8000 не открывается | подождите минуту после запуска; `docker ps` должен показать три контейнера `trs398_*` со статусом Up; `docker compose logs app` покажет ошибку |
| Порт 8000 или 5433 занят другой программой | в `.env` добавьте `APP_PORT=8080` (адрес станет `http://localhost:8080`) и выполните `docker compose up -d` |
| Диск заполнен | Docker Desktop → Troubleshoot → Clean / Purge data удалит всё, **включая базу программы**; сначала сделайте копию (`backup-now.bat`) и скопируйте папку `backups` |

## Linux или macOS

- **macOS:** Docker Desktop с того же сайта (выберите Apple chip или Intel chip), дальше то же самое. Запуск: `docker compose up -d --build`.
- **Linux (сервер без лицензионных ограничений):** установите Docker Engine и плагин Compose по инструкции
  https://docs.docker.com/engine/install/ (Ubuntu: `sudo apt install docker.io docker-compose-v2`), добавьте себя в группу:
  `sudo usermod -aG docker $USER` и перелогиньтесь. Затем: `cp .env.example .env`, задайте три пароля базы и `SESSION_SECRET`
  (длинные случайные строки), `docker compose up -d --build`. Автозапуск после перезагрузки: `sudo systemctl enable docker`.

## 8. Установка без интернета (из пакета)

Если на компьютере нет интернета и GitHub, используйте пакет `TRS398-<версия>-offline.zip` (его получает тот, кто выпускает версии, и приносит на флешке).
Docker Desktop и WSL 2 при этом нужно поставить заранее из установщиков, которые выдаст ИТ-отдел (в пакет они не входят).
Распакуйте пакет в папку без русских букв (например, `C:\trs398`) и запустите `start.bat`: образы программы загрузятся из пакета
(несколько минут, один раз), всё остальное как в разделе 5. Обновление: распакуйте новый пакет поверх старой папки и запустите `update.bat`.
Подробно: [PUBLISHING.md](PUBLISHING.md).
