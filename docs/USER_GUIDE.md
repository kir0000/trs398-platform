# Руководство пользователя

Платформа определения абсолютной дозы по IAEA TRS-398 Rev.1 (фотоны и электроны). Адрес: `https://localhost:8443` (при включённом HTTPS) или `http://localhost:8000`.

## Роли

| Роль | Что может |
|---|---|
| Наблюдатель | Смотреть измерения, тренды, неопределённость и сравнение энергий, печатать протоколы |
| Физик | То же, а также вносить измерения, отправлять их на проверку, заменять утверждённую запись, сохранять опорные значения пучка |
| Проверяющий | Утверждать или возвращать чужие измерения (свои утвердить нельзя) |
| Администратор | Оборудование, пользователи, журнал аудита, копии, очистка базы |

## 1. Один раз: раздел «Оборудование»

Оборудование изменяет администратор; физик и проверяющий его видят и используют. Раздел состоит из трёх вкладок:

- **Аппараты и пучки.** Слева список аппаратов, справа выбранный аппарат: его данные, таблицы пучков «Фотоны» и «Электроны» (одна строка на пучок, одна кнопка «Сохранить»).
  У каждого пучка есть индикатор готовности: «не хватает» (без *z*<sub>max</sub> или *PDD*(*z*<sub>ref</sub>) лист не заполнить), «заполнено не всё» или «✓ готов».
  Опорная точка при SAD и окно фантома для электронов спрятаны в раскрывающемся блоке под строкой пучка.
- **Пучок введён по ошибке.** Пучок без данных удаляется кнопкой «Удалить». Если у пучка уже есть записи, в меню «⋯» его строки есть два варианта:
  «В архив» (пучок исчезает из выбора нового измерения, записи и тренды остаются; «Вернуть из архива» отменяет) и, только если все записи пучка черновики или возвращённые,
  «Удалить пучок и его черновики» (импортированные записи журнала удаляются только по отдельной отметке). Утверждённые, замещённые и аннулированные записи — история, их удалить нельзя;
  неверную утверждённую запись сначала аннулируйте (раздел 4), а пучок отправьте в архив.
- **Дозиметры.** Камеры (тип и серийный номер) с историей калибровок, срок действия подсвечивается (истекает через 90 дней, истёк), электрометры, форма «Новая калибровка».
- **Опорные значения.** Наборы, сохранённые кнопкой «Сделать эти значения опорными» на листе измерения: для каждой пары «пучок + камера» видно, кто и когда их сохранил и что в них; удалить набор может администратор.

Все параметры разделов 1–3 рабочего листа (камера, *N*<sub>D,w</sub>, *Q*<sub>0</sub>, условия калибровки, электрометр, *k*<sub>elec</sub>,
полярность в лаборатории и у пользователя, «с поправкой», «калибруется отдельно от камеры») задаются **только здесь**.
На листе расчёта они подставляются автоматически и не меняются.

1. Добавьте аппарат (можно несколько) и его пучки (фотоны или электроны, энергия, FFF).
2. Добавьте камеру и электрометр, затем калибровку (*N*<sub>D,w</sub>, дата, «действует до», лаборатория, напряжение, *k*<sub>elec</sub>).
   Сверьте *N*<sub>D,w</sub> с сертификатом: для камер типа Farmer он обычно около 0,05 Гр/нКл, для плоскопараллельных около 0,5.
3. Для электронов укажите материал и толщину окна водного фантома, пластиковый фантом и коэффициенты *c*<sub>pl</sub>, *h*<sub>pl</sub>.
4. Если *k*<sub>elec</sub> калибруется отдельно от камеры (например, во ВНИИФТРИ), отметьте галочку и укажите лабораторию и дату.
5. Для каждого пучка внесите *PDD*(*z*<sub>ref</sub>) и *TMR*(*z*<sub>ref</sub>), MU при калибровке и, для SAD, ожидаемую дозу в опорной точке (см. раздел 6).

## 2. Новое измерение

1. «Измерения» → «Новое измерение»: выберите тип пучка, аппарат и энергию. Камеры с истёкшим сроком калибровки в списке недоступны
   (серые, «срок истёк»); сервер такую запись тоже отклонит. Даты калибровки и измерения не могут быть позже сегодняшней.
2. **Качество пучка *Q*.** Введите измеренное TPR<sub>20,10</sub> прямо (разд. 6.3 TRS-398 Rev.1) либо оставьте его пустым и введите PDD:
   для пучка с фильтром PDD(10) и PDD(20), для пучка без фильтра (FFF) только PDD(10); поле PDD(20) блокируется.
   Рядом с *Q* показан источник: «введено вручную», «рассчитано по PDD» или предупреждение, если введённое значение
   расходится с расчётным более чем на 0,003. В расчёт всегда идёт введённое значение.
3. **Геометрия.** При SSD вводится *PDD*(*z*<sub>ref</sub>), при SAD вводится *TMR*(*z*<sub>ref</sub>) или используется ожидаемая доза из «Оборудования»; неподходящее поле блокируется.
4. **Условия.** Давление *P* и температура *T* принимаются в пределах 80–110 кПа и 10–35 °C. Влажность по умолчанию 50 %; в диапазоне 20–80 % её влиянием
   на показания можно пренебречь (по TRS-398), вне диапазона появляется предупреждение.
5. **Показания.** Введите серии через пробел. Рядом с каждой серией показаны среднее и дрейф: наклон линии тренда по серии
   в % от среднего (зелёный до 0,2 %, жёлтый до 0,5 %, красный больше). Берите серию без дрейфа в одну сторону.
6. **Поправки (iii) и (iv).** Нужны две серии для полярности (*M*₊ при +*V*₁ и *M*₋ при −*V*₁) и две для рекомбинации
   (*M*₁ при *V*₁ и *M*₂ при *V*₂). *M* в формуле для *k*<sub>pol</sub> берётся из *M*₊ или *M*₋ по полярности пользователя из «Оборудования».
   Для нового измерения подставляются опорные показания пучка и камеры (если их сохранили), иначе первоначальные (первая утверждённая запись);
   любое значение можно изменить. Кнопки над блоком: «Подставить первоначальные показания пучка», «Подставить опорные показания» и
   «Сделать эти значения опорными». Последняя сохраняет значения открытого листа (качество пучка *Q*, серию *M* и MU, показания (iii) и (iv))
   как опорные для выбранного пучка и камеры (доступно физику и администратору, действие пишется в журнал аудита).
7. **Результат** закреплён внизу экрана и обновляется по мере ввода. Цвет по отклонению от 1 сГр/MU (при SAD от ожидаемой дозы): зелёный до 1 %,
   жёлтый 1–2 %, красный больше 2 %.
8. Знак «?» рядом с полем открывает пояснение. Сохраните запись как черновик, затем нажмите «Отправить на проверку».
   **Номер протокола** (вида `2026-0042`, нумерация по году измерения) присваивает база сама при сохранении, вводить его не нужно;
   он виден в списке, в карточке записи и в напечатанном протоколе и не меняется. В поле «Примечание» пишите только комментарий.

## 3. Проверка

Второй человек открывает запись из списка «на проверке», сверяет данные и нажимает «Утвердить» или «Вернуть».
Автор утвердить свою запись не может (ограничение и в приложении, и в базе).
Утверждённая запись неизменяема; исправление делается заменой (новая запись, старая получает статус «заменено»).

## 4. Удаление и аннулирование записи

- **Черновик или «возвращено».** На странице записи есть кнопка «Удалить» (автор или администратор). Запись исчезает, номер протокола
  не используется повторно, а в журнале аудита остаётся, кто, какой номер и когда удалил.
- **Утверждённая запись.** Удалить её нельзя. Администратор нажимает «Аннулировать» и указывает причину (не короче 5 символов). Запись остаётся
  в базе со статусом «аннулировано», исчезает из трендов, сравнения энергий и бюджета неопределённости, а протокол печатается с отметкой
  «АННУЛИРОВАНО». Если аннулируется исправленная копия (замена), заменённая ею запись снова становится действующей.
- **Нужна исправленная запись, а не просто отмена.** Используйте «Заменить».

## 5. Печать протокола

Откройте запись и нажмите «Печать» (страница) или «PDF». Форма повторяет рабочий лист. Приложение «Оценка неопределённости» по умолчанию краткое
(одна страница: составляющие, *u*<sub>c</sub>, *U*, вывод); на экране печати можно выбрать «полностью» (все таблицы, форма распределения и формула каждой составляющей,
примечания, решение о перекалибровке) или «без приложения». Протокол печатается на языке интерфейса; другой язык: добавьте к адресу `?lang=ru` или `?lang=en`.

## 6. Тренды и анализ

- **Тренды.** Карта Шухарта (I-MR), правила Western Electric, CUSUM и прогноз выхода за допуск по выбранному пучку.
  Для SAD доза определяется в опорной точке (изоцентр на опорной глубине) без пересчёта на *z*<sub>max</sub>. В «Оборудовании» для пучка задаются
  ожидаемая доза в опорной точке (сГр/MU, из системы планирования), глубина этой точки и источник значения, а также MU при калибровке
  (подставляется в новый лист). При SAD отклонение считается от ожидаемой дозы. Каждый набор опорных условий (SSD; SAD с данной глубиной, полем и
  ожидаемой дозой) образует отдельный ряд тренда со своими границами и CUSUM; ряд выбирается списком на странице «Тренды», значения из разных условий не смешиваются.
  Если изменить ожидаемую дозу или глубину, новые записи попадают в новый ряд, а старые остаются в прежнем.
- **Базовые периоды** (администратор). Каждый период начинает свой отрезок статистики: границы и накопленные суммы CUSUM считаются заново с его первой записи
  (например, после юстировки). Записи до первого периода показываются серым, без границ и сигналов.
- **Неопределённость.** Бюджет по TRS-398 (таблицы 17/24/25), тип A из журнала, *u*<sub>c</sub>, *U* (*k* = 2), рекомендация по перекалибровке.
  Значения типа B можно менять под условия учреждения и аккредитацию лаборатории (поля таблицы, кнопка «Сохранить значения»; «Вернуть значения по умолчанию» отменяет изменения),
  а также добавлять свои строки, в том числе готовые из литературы (TG-51 Addendum, McDermott 2024). Изменённые и добавленные значения помечаются и попадают в приложение к протоколу;
  менять их могут физик и администратор, изменения пишутся в журнал аудита. Внизу страницы находится таблица сравнения с опубликованными бюджетами.
  В таблицах бюджета для каждой составляющей указаны форма распределения (нормальное, прямоугольное, треугольное, U-образное) и формула, по которой её значение получают из исходных данных
  (*u* = *U*/*k*, *a*/√3 и т. д.). Общие формулы и правила чувствительности для разных энергий даны в карточке «Как получают стандартную неопределённость»,
  а распределения входных данных работы McDermott 2024 приведены под таблицей сравнения. В свою строку можно ввести распределение, параметр (*a*, σ или *U* с *k*) и чувствительность *c*:
  значение *u* считается автоматически.
- **Сравнение энергий.** Все пучки одного аппарата на одном графике, тепловая карта по месяцам, корреляции, поиск общего сдвига. Графики следуют за фильтрами таблицы состояния энергий.

Таблицы сортируются щелчком по заголовку; шапка страницы закреплена.

### Как читать CUSUM

CUSUM накапливает небольшие отклонения от центральной линии CL и поэтому раньше карты Шухарта замечает медленный дрейф
или небольшой постоянный сдвиг. Каждая запись добавляет к сумме своё отклонение от CL, уменьшенное на допуск *k* = 0,5σ; C⁺ растёт при выходе
выше CL, C⁻ падает при выходе ниже, обе не заходят за ноль. Сигнал подаётся, когда C⁺ больше *H* = 5σ (сдвиг вверх) или C⁻ меньше −*H* (сдвиг вниз).

- **Пример.** При σ = 0,3 % и выходе на 0,3 % выше CL порог проходится примерно на 10-й записи, а карта с границами ±0,9 % такого сдвига не видит.
- **Повторные сигналы.** Сумма не обнуляется после сигнала, поэтому подряд идущие сигналы относятся к одному сдвигу; начало сдвига там, откуда сумма пошла вверх.
- **Что делать.** Сигнал даёт повод проверить условия измерения (давление, температура, камера, электрометр, монитор, выход ускорителя), а не вывод о неисправности.
- **Ограничения.** Границы считаются по самому журналу: если в него попал уже сдвинутый ряд, задайте базовый период по стабильному времени.
  Решение о перекалибровке принимается по отклонению от 1 сГр/MU и по неопределённости, а не по CUSUM.

Та же памятка есть на странице «Тренды» (раскрывающийся блок «Как читать CUSUM»).

## 7. Язык интерфейса

Переключатель **EN / RU** находится в верхней строке (на странице входа справа вверху). Выбор запоминается в браузере; язык по умолчанию задаёт `TRS_LANG` в файле `.env`.

Язык интерфейса, кодировка и десятичный разделитель не зависят от языка и региональных настроек Windows. Страницы всегда в UTF-8; на русском в числах запятая (`2,5`), на английском точка (`2.5`),
а вводить можно и так и так. От региона компьютера зависит только вид стандартных полей браузера (например, календаря даты: дд.мм.гггг или мм/дд/гггг).

## 8. Администратору

- «Пользователи»: создание учётных записей и ролей.
- «Аудит»: журнал действий (только добавление записей).
- «Копии»: состояние резервных копий, кнопка «Сделать копию сейчас», инструкция по восстановлению (`restore.bat`).
- «Очистка базы»: удаление данных (сначала проверьте плашку со свежестью резервной копии; слово подтверждения: УДАЛИТЬ или DELETE).
- Резервные копии: ежедневно в папку `backups/`, хранятся 30 дней. Проверка восстановления:

```bash
python tools/verify_backup.py
```

## 9. Глоссарий: термины и сокращения

### Протокол и физика

| Термин | Что означает |
|---|---|
| IAEA TRS-398 Rev.1 | Протокол МАГАТЭ (Technical Reports Series No. 398, пересмотр 1) по определению поглощённой дозы в воде для дистанционной лучевой терапии |
| TG-51, TG-142 | Рекомендации AAPM: TG-51 по калибровке пучков, TG-142 по контролю качества ускорителей (допуски) |
| SSD (source–surface distance) | Расстояние от источника до поверхности фантома; обычная геометрия измерения, 100 см |
| SAD (source–axis distance) | Расстояние от источника до оси вращения (изоцентра), 100 см; камера на заданной глубине в изоцентре |
| SCD | Расстояние источник–центр камеры: SCD = SSD + *z*<sub>ref</sub> |
| FFF (flattening filter free) | Пучок без выравнивающего фильтра; при пучке с фильтром (WFF) нужны PDD(10) и PDD(20), при FFF только PDD(10) |
| MU (monitor unit) | Мониторная единица ускорителя |
| *z*<sub>ref</sub> | Референсная глубина, на которой стоит камера (фотоны обычно 10 г/см²; электроны 0,6·*R*<sub>50</sub> − 0,1) |
| *z*<sub>max</sub> | Глубина максимума дозы |
| PDD(*z*) | Процентная глубинная доза на глубине *z*; PDD(10), PDD(20) при SSD 100 см |
| TMR | Отношение ткань–максимум (tissue–maximum ratio), для SAD |
| TPR<sub>20,10</sub> | Отношение показаний на глубинах 20 и 10 см при постоянном расстоянии источник–камера: индекс качества фотонного пучка |
| *R*<sub>50</sub> | Глубина, на которой доза составляет 50 % от максимума; индекс качества электронного пучка |
| *Q*, *Q*<sub>0</sub> | Качество пучка пользователя и опорное качество калибровки (обычно ⁶⁰Co) |
| *N*<sub>D,w</sub> | Калибровочный коэффициент камеры по поглощённой дозе в воде, Гр/нКл |
| *M*, *M*<sub>+</sub>, *M*<sub>−</sub>, *M*<sub>1</sub>, *M*<sub>2</sub> | Показания электрометра, нКл: при полярности пользователя, при положительной и отрицательной полярности, при напряжениях *V*<sub>1</sub> и *V*<sub>2</sub> |
| *V*<sub>1</sub>, *V*<sub>2</sub> | Рабочее и пониженное напряжения камеры, В (метод двух напряжений) |
| *k*<sub>TP</sub> | Поправка на давление и температуру воздуха |
| *k*<sub>pol</sub> | Поправка на полярность |
| *k*<sub>s</sub> | Поправка на неполный сбор заряда (рекомбинация) |
| *k*<sub>vol</sub> | Поправка на объёмный эффект (для пучков FFF) |
| *k*<sub>elec</sub> | Поправка на калибровку электрометра |
| *k*<sub>Q,Q0</sub> | Поправка на качество пучка |
| *c*<sub>pl</sub>, *h*<sub>pl</sub> | Поправки на пластиковый фантом (глубина и флюенс), электроны |
| *D*<sub>w</sub>(*z*<sub>ref</sub>), *D*<sub>w</sub>(*z*<sub>max</sub>) | Поглощённая доза в воде на референсной глубине и на глубине максимума, Гр/MU |
