# Доступ с нескольких компьютеров (локальная сеть)

Программа ставится **на одном компьютере** (сервере), остальные физики открывают её в браузере, ничего ставить не нужно.

## Как это устроено

Docker запущен только на **сервере**. Внутри контейнера работает сайт; Docker «пробрасывает» его порт 8000 на компьютер-сервер.
Остальным компьютерам Docker, Python и сама программа **не нужны**: достаточно браузера (Chrome, Edge, Firefox) и адреса сервера,
как у любого внутреннего сайта. Данные и пользователи общие, хранятся на сервере. Пока доступ из сети выключен (по умолчанию),
сайт открывается только на самом сервере по адресу `http://localhost:8000`.

## Включить

1. На компьютере-сервере запустите `start.bat` (один раз), затем **`lan-on.bat`**. Окно запросит права администратора:
   нужно открыть порт 8000 в брандмауэре Windows (только для частной и доменной сети).
2. Скрипт покажет адреса, например `http://PC-FIZIKA:8000` и `http://192.168.1.20:8000`.
   Остальные открывают любой из них в браузере и входят под своей учётной записью.
3. Выключить доступ из сети: **`lan-off.bat`**.

Linux/macOS: добавьте в `.env` строку `APP_BIND=0.0.0.0`, откройте порт 8000 (`ufw allow 8000/tcp`), затем `docker compose up -d`.

## Что нужно знать

- Компьютер-сервер должен быть включён, а Docker Desktop запущен. Включите в Docker Desktop «Start Docker Desktop when you sign in»
  и в Windows отключите сон, иначе другие потеряют доступ.
- Дайте серверу постоянный адрес: в роутере закрепите за ним IP-адрес (или пользуйтесь именем компьютера).
- База данных остаётся закрытой: порт PostgreSQL (5433) доступен только на самом сервере.
- Каждому пользователю заведите отдельную учётную запись («Пользователи»): роли и правило двух лиц работают так же.
- Резервные копии лежат на сервере в папке `backups` (автоматически каждый день). Копируйте её на другой диск или сетевую папку.
- Без шифрования пароли идут по сети открытым текстом. Внутри закрытой больничной сети это обычно допустимо;
  если нужно шифрование, включите HTTPS (ниже). Не открывайте порт в интернет.

## Необязательно: HTTPS (шифрование)

1. На сервере запустите **`https-on.bat`** (запросит права администратора). Если в папке `certs` нет сертификата, скрипт создаст
   самоподписанный (`cert.pem`, `key.pem`, 825 дней, для имени компьютера и его IP-адресов), включит `HTTPS_ONLY=1`,
   закроет в брандмауэре порт 8000 для сети и откроет 8443. Нужен интернет один раз (скачивается маленький образ `alpine/openssl`).
2. Адрес для всех, в том числе на самом сервере: `https://имя-компьютера:8443`. Обычный `http://...:8000` для входа больше не работает.
3. Браузер при первом заходе предупредит о сертификате (он самоподписанный). Либо нажмите «Дополнительно → Перейти на сайт», либо
   один раз добавьте `certs\cert.pem` в доверенные корневые сертификаты каждого компьютера (двойной щелчок → «Установить сертификат» →
   «Локальный компьютер» → «Доверенные корневые центры сертификации»). Или попросите ИТ-отдел выпустить сертификат для имени сервера и
   положите его в `certs` под именами `cert.pem` и `key.pem` (до запуска `https-on.bat`).
4. Если сервер получит другой IP-адрес или имя, удалите папку `certs` и снова запустите `https-on.bat`.
5. Выключить: **`https-off.bat`** (программа снова доступна только на сервере по `http://localhost:8000`; для сети затем `lan-on.bat`).

Вручную (Linux/macOS): положите `cert.pem` и `key.pem` в `certs`, в `.env` добавьте `HTTPS_ONLY=1` и `APP_BIND=127.0.0.1`,
затем `docker compose up -d app` и `docker compose --profile https up -d`; порт 8443 откройте в брандмауэре.
