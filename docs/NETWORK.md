# Доступ с нескольких компьютеров (локальная сеть)

Программа работает **на одном ноутбуке** (его называют сервером), остальные физики открывают её в браузере, ничего ставить не нужно.
Серверы отделения, которые являются медицинскими изделиями, для этого не используются: подходит любой обычный ноутбук с Windows, который в рабочее время включён и подключён к той же сети.

## Включить

1. На ноутбуке с программой отметьте **«Разрешить подключение с других компьютеров»**: в меню значка в трее или на странице **«Настройки»** (администратор). Там же меняется порт.
   Программа покажет адрес вида `http://192.168.1.20:8000`.
2. При первом включении Windows спросит разрешение брандмауэра: отметьте **«Частные сети»** и нажмите «Разрешить».
   Это единственное действие, которому нужны права администратора Windows (разрешить входящие соединения программе). Если их нет, попросите администратора компьютера один раз нажать «Разрешить» или создать правило для порта 8000. Работа на одном ноутбуке (`http://localhost:8000`) прав администратора не требует.
3. Остальные открывают этот адрес в браузере и входят под своей учётной записью (создаёт администратор в «Пользователях»).
   Имя ноутбука (`http://имя-ноутбука:8000`) удобнее адреса, потому что адрес может меняться.
4. Выключить: снять отметку в том же меню.

## Ограничение доступа

Администратор: «Настройки» → «Безопасность сети».

- **Разрешённые адреса.** Пусто: подключаться можно с любого адреса сети (по умолчанию). Если указать адреса и сети (`192.168.1.0/24, 10.0.0.15`), остальные получат страницу «403, доступ с этого адреса не разрешён». Сам ноутбук (`127.0.0.1`) разрешён всегда. Программа не даёт сохранить список, в котором нет вашего собственного адреса (иначе вы закрыли бы доступ себе). Отклонённые обращения записываются в журнал аудита (не чаще раза в час для одного адреса). Адрес ноутбуку лучше закрепить в роутере, чтобы он не менялся. Переменная окружения `TRS_ALLOWED_NETWORKS` сильнее настройки.
- **Срок сеанса.** «Сеанс не дольше» (часов, по умолчанию 8): после этого срока нужно войти заново. «Завершать сеанс после простоя» (минут, 0 — не завершать): для общих ноутбуков разумно 30–60; несохранённая форма при завершении сеанса теряется. На странице входа будет написано, почему сеанс закончился.

Это не заменяет шифрование: соединение по-прежнему http.

## Что учесть

- Пока ноутбук-сервер выключен или спит, остальные не могут работать. Отключите спящий режим при питании от сети.
- Соединение не шифруется (http): пароли идут по сети открытым текстом. Используйте только во внутренней сети отделения, не открывайте порт в интернет. HTTPS в версии 2.0 не включён.
- Копии базы лежат на ноутбуке-сервере; копируйте папку `backups` на другой носитель.
- Одновременная работа 2–5 человек безопасна: база — файл SQLite, записи выполняются по очереди.
- Если ноутбук в другой подсети или сеть блокирует соединения между компьютерами, обратитесь к администратору сети: нужно разрешить входящие TCP-соединения на порт 8000.
