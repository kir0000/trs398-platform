# TRS-398 Rev.1: определение абсолютной дозы

*English version: [README.en.md](README.en.md)*

Веб-платформа для расчёта поглощённой дозы в воде по TRS-398 Rev.1 (фотоны и электроны высоких энергий):
база данных PostgreSQL, роли, утверждение вторым лицом, тренды выхода (контрольные карты, CUSUM) и печать
протокола в PDF по форме рабочего листа «Расчёт». Интерфейс и скрипты запуска работают на **русском и английском** (переключатель RU / EN в верхней строке программы).

> Образовательное и исследовательское использование. Программа не является сертифицированным медицинским
> изделием: каждый результат нужно проверять независимо. См. [NOTICE.md](NOTICE.md).

## Установка за три шага (Windows)

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/) и запустите его (подробно с настройками: [docs/INSTALL.md](docs/INSTALL.md), English: [docs/INSTALL.en.md](docs/INSTALL.en.md)).
2. Скачайте проект (на GitHub: **Code → Download ZIP**, распакуйте в удобную папку, например `C:\trs398`) или `git clone`.
3. Дважды щёлкните **`start.bat`**. Он проверит компьютер, спросит язык (русский или английский), первый запуск занимает несколько минут (собирается приложение), затем сам откроется
   http://localhost:8000 и спросит, **какой логин и пароль у администратора**: придумайте свои. Дальше:
   «Пользователи» (добавить физиков и проверяющих), «Оборудование» (аппарат, пучки, камера и калибровка), «Измерения».

Linux/macOS: `cp .env.example .env`, задайте три пароля базы и `SESSION_SECRET`, затем `docker compose up -d --build`.

| Файл | Что делает |
|---|---|
| `start.bat` / `stop.bat` | запустить / остановить (данные сохраняются) |
| `lan-on.bat` / `lan-off.bat`, `https-on.bat` / `https-off.bat` (HTTPS) | открыть программу другим компьютерам сети / закрыть ([docs/NETWORK.md](docs/NETWORK.md)) |
| `backup-now.bat` | резервная копия базы сейчас |
| `restore.bat` | заменить базу копией (см. ниже) |
| `update.bat` | обновить программу до новой версии (сначала делает копию) |
| `language.bat` | выбрать язык скриптов и программы (русский / English) |

Один компьютер-сервер, много рабочих мест: на сервере выполните `lan-on.bat`, остальные открывают в браузере
`http://имя-компьютера:8000`. Подробности и необязательный HTTPS: [docs/NETWORK.md](docs/NETWORK.md). Руководство для физиков: [docs/USER_GUIDE.md](docs/USER_GUIDE.md) (есть и в самой программе, пункт «Справка»).

Данные хранятся в томе Docker `trs398_pgdata`, копии баз лежат в папке `backups` проекта.

### Резервные копии и восстановление

Служба `backup` (контейнер `trs398_backup`) делает копию при запуске и затем каждый день в 02:00 (время контейнера, UTC),
хранит 30 дней (`BACKUP_HOUR`, `BACKUP_KEEP_DAYS` в `.env`). Файлы: `backups/trs398_ГГГГ-ММ-ДД_ЧЧММСС.sql.gz`;
в них данные пользователей и хэши паролей, держите папку закрытой (в git она не попадает). Копию в любой момент:
кнопка «Сделать копию сейчас» на странице **«Копии»** (меню администратора) или `backup-now.bat`.

**Восстановить:** запустите `restore.bat` (Linux/macOS: `./restore.sh`), выберите номер копии и введите `YES`.
Программа остановится, **текущая база сначала сохранится в `backups/keep`** (ошибочный выбор можно отменить тем же способом),
база заменится копией, программа запустится снова.

**Перенести на другой компьютер или переустановить:** установите программу (`start.bat`), положите файл копии в папку `backups`,
запустите `restore.bat имя_файла`. Пароли пользователей переносятся вместе с копией.

**Новая пустая база:** остановите программу (`stop.bat`), выполните `docker compose down -v` (удаляет том с данными;
сначала `backup-now.bat` и скопируйте файл куда-нибудь), затем `start.bat`: браузер снова предложит создать администратора.

Проверить, что последняя копия читается (она загружается во временную базу и сверяется с рабочей, рабочая только читается):
`python tools/verify_backup.py`. Проверить, что все сохранённые результаты воспроизводятся из исходных данных:
`docker exec -i trs398_app python - < tools/recompute_check.py` (PowerShell: `Get-Content tools/recompute_check.py -Raw | docker exec -i trs398_app python -`).

## Что умеет

- Фотоны и электроны: kTP, kpol, ks (метод двух напряжений), kvol (FFF), kQ (Таблицы 16, 20, 21), Dw(zref), Dw(zmax).
- Рабочий процесс: черновик → на проверке → утверждено (или возвращено). Автор не может утвердить свою запись.
  Утверждённую запись нельзя изменить, только заменить с указанием причины.
- **Протокол**: страница печати и PDF (кнопки «Печать» и «Скачать PDF») в виде листа «Расчёт» (жёлтые, голубые и зелёные ячейки, формулы, галочки) плюс приложение «Оценка неопределённости» (этапы 1–2, тип A по журналу, uc и U, примечания, решение о перекалибровке) по листу «Неопределённость».
- **Сравнение энергий** (меню «Сравнение энергий»): все энергии одного аппарата вместе: состояние каждой, наложенные ряды, карта «энергия × месяц», поиск общего сдвига нескольких энергий в один месяц и корреляции между энергиями.
- Таблицы сортируются по клику на заголовок, верхняя панель и шапки таблиц закреплены.
- Параметры разделов 1–3 листа (аппарат, пучок, камера, калибровка, полярности, электрометр) задаются в «Оборудовании»; на листе расчёта они только показываются. Показания (iii) и (iv) подставляются из первой записи пучка и их можно менять.
- Тренды: контрольные границы ±2σ/±3σ, правила сигналов, CUSUM, прогноз выхода за ±2 %, фиксируемый базовый период.
- Администратор: пользователи, оборудование, журнал аудита, копии, очистка базы.
- Два языка (русский, английский) интерфейса, протокола/PDF, справки и скриптов запуска.

## Роли

| Роль | Права |
|---|---|
| наблюдатель | просмотр измерений и трендов |
| физик | ввод измерений, отправка на проверку, калибровки камер |
| проверяющий | утверждение и возврат чужих записей, замена утверждённых |
| администратор | всё выше, пользователи, аппараты и пучки, базовый период SPC, журнал аудита, очистка базы |

## Очистка базы

Администратор: меню «Очистка базы». Нужны выбор области, причина, пароль и слово `УДАЛИТЬ` (в английском интерфейсе `DELETE`). Удаляются
измерения/результаты и/или исторические журналы. Пользователи, оборудование, справочники и журнал аудита
сохраняются, сама очистка записывается в аудит. У роли приложения нет права `DELETE`: удаление возможно только через
защищённую функцию `admin_purge()` и только для активного администратора. Перед очисткой сделайте резервную копию.

## Демонстрационные данные

`python tools/seed_demo.py` заполняет базу на 2 года (ежемесячно): **2 аппарата** (TrueBeam, Versa HD) и **15 пучков**: фотоны 6, 6 FFF, 10 FFF, 15 MV и электроны 6, 9, 12, 15 MeV (360 утверждённых записей).
Камеры и калибровки (условные значения): у TrueBeam по шаблонам 2.0 (SNC600c Farmer, ND,w = 0,05138 Гр/нКл; PTW 34001 Roos, ND,w = 0,5791 Гр/нКл),
у Versa HD свои (PTW 30013 Farmer и IBA NACP-02, электрометр IBA Dose1), плюс две резервные камеры с действующей калибровкой (IBA FC65-G Farmer, второй PTW 34001 Roos).
У каждой рабочей камеры две калибровки: прошлая (истекла, в форме недоступна) и действующая. Записи помечены DEMO, выполнены «Демо-физиком» и утверждены «Демо-проверяющим»
(отключённые учётные записи, войти под ними нельзя). В данных есть что показать: выход за допуск и перенастройка (Versa HD 6 MV), медленный дрейф (TrueBeam 12 MeV),
общий сдвиг нескольких энергий в один месяц (TrueBeam). Пучки с вашими реальными данными пропускаются. Удалить только добавленное: `python tools/seed_demo.py --remove`.
Перед запуском сделайте резервную копию (`backup-now.bat`). Скрипту нужен `.env` с паролем владельца базы и запущенная программа.

## Разработка

```
python -m venv .venv && .venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python -m pytest -q tests
```

Сквозные тесты используют отдельную базу `trs398_test` на работающем контейнере `trs398_db` (порт 5433) и не
трогают рабочие данные; без базы они пропускаются. PDF формируется WeasyPrint, он входит в Docker-образ.

### Языки

Русский — исходный язык интерфейса, английский берётся из справочника фраз `app/i18n/en.json` (`app/i18n.py` переводит готовую страницу).
После изменения любого русского текста интерфейса: `python tools/i18n_extract.py` показывает фразы без английского текста, `--todo файл.json` выгружает их для перевода,
`--merge файл.json` загружает переводы. Тест `tests/test_i18n.py` падает, если у фразы нет английского текста или на странице в английском режиме остался русский.
Скрипты берут язык из `TRS_LANG` в `.env` (сообщения: `tools/msg.ru.bat` и `tools/msg.en.bat`, проверки: `tools/preflight.ps1`).

## Структура

- `core/`: расчёт (фотоны, электроны, SPC), справочные таблицы в `core/data/`
- `app/`: веб-приложение (FastAPI, Jinja2, HTMX), `app/protocol.py` собирает данные протокола
- `db/init/`: схема, роли, миграции
- `importers/`: перенос таблиц и журналов из xlsm (только чтение)
- `docs/DESIGN.md`: разбор исходных таблиц, формулы, модель данных (English: `docs/DESIGN.en.md`)
